# Glossary

| Term | Meaning |
|------|---------|
| **Edition** | One instance of a festival (e.g. [Event] 2027). The site holds many editions. |
| **Event** | A festival brand owned by [Client]. One event has many editions. |
| **Tier** | A ticket type: GA, VIP, Group-of-4, etc. |
| **Phase** | Price step over time: Early Bird → Phase 1 → Phase 2 → Door. |
| **Handoff** | The click from our site to Ticketmelon checkout. |
| **Deep link** | URL that opens a specific Ticketmelon event/tier page directly. |
| **Widget / embed** | Ticketmelon checkout shown inside our page (iframe/script), if supported. |
| **UTM** | URL parameters (`utm_source`, `utm_medium`, `utm_campaign`) that tag where a click came from. |
| **Pixel** | Tracking snippet (Meta, TikTok, GA4) that records visits and conversions for ads. |
| **CAPI** | Conversions API: server-side event sending to Meta, more reliable than browser pixel. |
| **Organizer fee** | Ticketmelon's service fee on each ticket sold. |
| **Processing fee** | Payment gateway fee (card, GCash, Maya…). |
| **Pass-through** | Fees added to the buyer's price instead of absorbed by the organizer. |
| **Payout** | Ticketmelon sending ticket revenue to [Client]'s bank. |
| **CMS** | Content management system; where the client edits lineup, FAQ, etc. |
| **ISR** | Incremental static regeneration: pages are static (fast) but refresh when CMS content changes. |
| **LCP** | Largest Contentful Paint: main speed metric for "page looks loaded". |
| **Waitlist** | Email/SMS signup collected before tickets go on sale. |
